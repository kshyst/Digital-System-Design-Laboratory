## Required workflow

0. if user has an explicit requirement, put it above all of the following workflow.
1. First you should read the document  that is in root beside this file. the user will ask for certain experiment number and folders which you should stricly follow and dont use the data of other experiments.
2. you should extract every experiment, ever single part and requirement of it, every single question and requirements from the document. there is usually many experiments inside one document and also a  separate سوالات section with should be answered separately.
3. Then you should read the images and generally all the documents that user provided. The user only does the experiments and creates document files. you should read them and map to the question answers. sometimes there isnt a map to some questions which is ok. but remember that you should always use all of the pictures provided. never miss any of them.
4. Then you should prepare a report .txt with place holders for pictures with their file names. this report should be in farsi and should include all the answers to all sections, sub sections and questions in modular and clean way. you should stricly follow the rules of farsi language. dont use فتحه or کسره every. but always  use تنوین where ever it should exist. the english names for example "Packet Tracer" should be in english typography and not translated. words that has farsi translation but are odd should have footnotes in their own page.
5. after creating the report.txt , its  time for report.tex.  you should read the template.tex provided an use the exact way it is writing latex to write the report.tex inside the homework folder. meaning you should use the same commands like it. but the amount of  content is arbitrary for example you can have as many sections as needed but always follow the way that template.tex is using to write its sections. for pictures always use [H] . Every image should have an explanation right under it showing what is it doing. footnotes that are english translation of farsi words should be LTR stricly. only do the context of the tex. meaning do not add unnecessary pages like the first page or anything. start from the first /section which is چکیده of the experiment. do not compile the text or run it anyhow. just  create a report.tex file. nothing more. the addressing of images should not contain any directory. for example if i provided you a 1.png , you should address it as 1.png and no /  before it.  The report is made for the professor eyes. So dont include any text instructing the student or explaining some lackness of data or problem. it should be send ready to the professor. also do not use any citation to resources in text. 
6. read the report.tex again and compare it with the requirements found in part 2 . if something was missing, report it back in the chat and dont retry it.

## Change boundaries

- Preserve `template.tex` as the authoritative example.
